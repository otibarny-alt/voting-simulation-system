V23.206 — County-wide unopposed candidate list

1. County is now the first and required filter on the Unopposed Candidates page.
2. A county-only search expands through every constituency and ward in county_main.csv.
3. The result combines all applicable unopposed President, Governor, Senator, Woman Representative, MNA and MCA contests.
4. Constituency and ward filters narrow the list only when the administrator selects them.
5. Candidate API calls for independent electoral scopes run concurrently with per-scope caching to avoid a slow serial county scan.
