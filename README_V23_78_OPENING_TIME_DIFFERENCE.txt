V23.78 — PRECISE OPENING-TIME DIFFERENCE

The Opening Check now calculates and displays the exact magnitude and direction
of the difference between the scheduled and actual stream opening times.

Examples:
- ON SCHEDULE — NO TIME DIFFERENCE
- LATE BY 12 HOURS, 13 MINUTES, 54 SECONDS
- EARLY BY 8 MINUTES, 5 SECONDS

The same result appears on the browser report, printed report, emailed PDF and
automatically deposited opening-repository PDF. Viewing an older opening report
after deployment safely regenerates its archived PDF with the precise result.

Deploy this package to the main Voting Simulation System service only.
