V23.188 COUNTY-WIDE CONSTITUENCY AND WARD TOTALS

The Voter Totals web preview and PDF now support:
- all constituencies in a selected county; and
- all wards across every constituency in a selected county.

For ward totals, selecting a constituency is optional. If one is selected,
the report narrows to that constituency; if it is left as "All
constituencies", every ward in the county is included with its constituency
shown in the results.

Polling-station totals continue to require county, constituency and ward to
prevent oversized reports. No database migration is required.
