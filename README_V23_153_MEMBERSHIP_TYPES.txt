V23.153 - MEMBERSHIP TYPES

- Adds Membership Type to the PostgreSQL master voters register.
- Ordinary Member is the default for imported and newly registered members.
- Candidate Portal approval changes the member to Life Member.
- Administrator approval of an agent changes the member to Election Official.
- Life Member takes precedence when the same person is also an election official.
- Shows Membership Type in the voters-register screen, CSV and printable PDF.
- Adds a Membership Type filter to the web register, CSV and PDF exports.

Deploy the coordinated Voting, Candidate and Verification packages together.
