V23.196 - ELECTION POSITION BALLOT HEADINGS

1. Replaced the fixed "EMERGENCY PAPER BALLOT" heading with the election
   position of the individual ballot.
2. Headings now display PRESIDENT, GOVERNOR, SENATOR, WOMAN REPRESENTATIVE,
   MNA or MCA as appropriate.
3. The change applies to both filtered web previews and downloaded PDFs.
4. The ballot footer now reads "OFFICIAL NOMINATION BALLOT" instead of the
   former emergency-paper-ballot wording.
5. All prior ballot formatting, full polling-station codes, cropped banner,
   watermarks and dynamic page heights remain unchanged.
6. No database migration is required.
