V23.145 - Independent Voter Polling Centre Lookup

- Adds /voter-polling-center-lookup as an independent public address.
- A 7- or 8-digit National ID returns only the voter's registered name and
  assigned polling centre.
- Serial number, phone, membership number and other voter details are hidden.
- The page has no navigation path into Admin Data Files or the full register.
- Responses are marked no-store and noindex.
- Admin Data Files includes a separate link for administrators to copy/open.
