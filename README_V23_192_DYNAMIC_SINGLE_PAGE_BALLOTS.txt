V23.192 - DYNAMIC SINGLE-PAGE BALLOTS

1. Removed the visible candidate number, candidate ID and ODM registration
   number from ballot candidate entries. Ballots now show only the candidate
   photograph, candidate name and voting checkbox.
2. Increased the checkbox column width in the web preview and PDF.
3. Standard candidate lists continue to use A5 ballot height.
4. When a position has more candidates than fit at standard A5 height, only
   that position's ballot grows vertically. Every candidate remains on the
   same PDF page, including crowded MCA ballots.
5. Tiled ODM watermarks automatically extend across the full dynamic page.
6. No database migration is required.
