V23.203 - BALLOT PRINT QUANTITIES

1. Keeps the voter totals PDF in A4 landscape format.
2. Keeps green tick and red X ballot-availability marks in the printed PDF.
3. Adds a final Ballot Papers Required section for President, Governor,
   Senator, Woman Representative, MNA and MCA.
4. For each displayed geography row, the required quantity for a category is
   the registered-voter count when an approved ballot exists, otherwise zero.
5. The section totals quantities across the active report filter and includes
   a grand total of all ballot papers to print.
6. Bundles Unicode-capable fonts so tick and X marks render consistently on
   Render and in downloaded PDFs.

No database migration is required.
