V23.187 VOTER TOTALS WEB PREVIEW

Adds a protected web preview to the Voter Totals report page.

Administrators can now:
1. Select the grouping and geographic filters.
2. Click "Preview Filtered Totals" to review every geographic row, source
   reconciliation and grand total in the browser.
3. Download the same selected scope as a branded PDF.

The preview and PDF call the same combined-voter aggregation function, so they
cannot calculate from different register sources. No database migration is
required.
