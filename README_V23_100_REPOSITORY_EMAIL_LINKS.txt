V23.100 — EMAIL ANY ARCHIVED REPORT

Adds an Email button beside View, Download and Delete for:
- Every archived voting-stream opening report.
- Presidential closing reports.
- Gubernatorial closing reports.
- Senatorial closing reports.
- Women Representative closing reports.
- MNA closing reports.
- MCA closing reports.

The administrator enters a recipient address and the exact stored PDF is
attached to the email. The report is not regenerated.

Security:
- Email actions require an authenticated repository administrator.
- Public visitors may still view/download reports but cannot send email.
- Recipient addresses are validated server-side.

Existing Render SMTP environment settings are reused. This package includes
all V23.99 registered-voter-total and V23.98 terminal-session fixes.
