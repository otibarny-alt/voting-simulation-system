V23.205 - UNIVERSAL ODM VOTING SYSTEM BANNER

The supplied ODM 2027 Party Primaries / ECC Voting System banner now replaces
the previous 20th Anniversary / General Elections banner throughout the voting
system.

Coverage includes:
- voter polling-centre lookup and ID-to-serial lookup;
- verification, voting, review and completion screens;
- stream control, tally and terminal interruption screens;
- opening and closing report repositories;
- membership and party-branding pages that use the shared ODM header;
- standard screen and report header compatibility files.

The separate ODM Nominations Ballot Paper banner used on emergency printable
ballots remains unchanged.

No database migration is required.
