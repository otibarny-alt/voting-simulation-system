V23.77 — DISTINCT OPENING REPORT GEOGRAPHY

- Adds County, Constituency and Ward to the on-screen opening report.
- Adds County, Constituency and Ward to the formatted A4/PDF opening report.
- Archived, downloaded and emailed opening-report filenames now contain the
  complete geographic identity: county, constituency, ward, polling station
  and stream.
- The repository's existing full-geography uniqueness key is retained, so
  identically named polling stations or streams in different areas remain
  separate records.

Deploy this package to the main Voting Simulation System service only.
